# 🌙 Тихий вечер — Telegram-бот воронки

Бот автоматизирует воронку продаж мини-программы «Тихий вечер»:
- Выдаёт лид-магнит по ключевому слову `СОН`
- Отправляет описание продукта по слову `ТИХО`
- Автоматический прогрев (5 сообщений)
- Приём оплаты через Tinkoff/ЮKassa
- Автоматическая доставка 7-дневной программы
- Аналитика воронки

## 🚀 Быстрый старт

### 1. Получить токен бота

Напишите [@BotFather](https://t.me/BotFather) в Telegram:
```
/newbot
```
Назовите бота (например: `Тихий вечер`), выберите username (например: `TihiyVecherBot`).

Скопируйте токен.

### 2. Настроить окружение

```bash
cp .env.example .env
```

Отредактируйте `.env`:
```
BOT_TOKEN=ваш_токен_от_BotFather
ADMIN_TELEGRAM_ID=ваш_telegram_id
```

> 💡 Чтобы узнать свой Telegram ID, напишите [@userinfobot](https://t.me/userinfobot)

### 3. Запуск через Docker (рекомендуется)

```bash
docker-compose up -d
```

Проверить логи:
```bash
docker-compose logs -f bot
```

Остановить:
```bash
docker-compose down
```

### 4. Запуск без Docker (для разработки)

```bash
# Создать виртуальное окружение
python -m venv .venv
source .venv/bin/activate  # Linux/Mac
# .venv\Scripts\activate   # Windows

# Установить зависимости
pip install -e .

# Запустить
python -m src.main
```

## ✏️ Как менять тексты бота

Все тексты находятся в одном файле:
```
src/bot/messages.py
```

Просто открой и отредактируй нужную переменную. Перезапусти бота.
