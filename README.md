# 🌙 Тихий вечер — система запуска цифрового продукта

Репозиторий проекта **«Тихий вечер»** — 7-дневной мини-программы в Telegram про сон, вечерний стресс и утреннюю разбитость для женщин 27–42.

## 🎯 Продукт в одном предложении

**«Тихий вечер»** — 7-дневный Telegram-reset для женщин 27–42, которые устают за день, но не могут выключиться вечером. Цена бета-запуска: **1990 ₽**.

Подробнее → [docs/01-product-brief.md](docs/01-product-brief.md)

## 🚀 С чего начать запуск

1. **Прочитай** [docs/01-product-brief.md](docs/01-product-brief.md) — поймёшь, что именно продаём
2. **Изучи** [docs/02-sales-funnel.md](docs/02-sales-funnel.md) — поймёшь логику продаж
3. **Упакуй профиль** по [docs/08-instagram-profile.md](docs/08-instagram-profile.md)
4. **Сделай PDF** из [docs/03-lead-magnet.md](docs/03-lead-magnet.md) (Canva → 25–35 страниц)
5. **Опубликуй** первый рилс из [docs/05-reels-scripts.md](docs/05-reels-scripts.md)
6. **Веди по плану** из [docs/04-content-plan-30days.md](docs/04-content-plan-30days.md)
7. **Отвечай в директе** по [docs/07-dm-templates.md](docs/07-dm-templates.md)
8. **Сверяйся** с [docs/09-launch-checklist.md](docs/09-launch-checklist.md)

## 🤖 Этап 2: автоматизация (план)

После того, как ручной запуск пойдёт, автоматизируем воронку:

- **Telegram-бот воронки** — приём ключевых слов `СОН` / `ТИХО`, выдача лид-магнита, прогрев, продажа
- **Платежи** — интеграция с Tinkoff / ЮKassa
- **Автопостинг** — публикации в Telegram-канал по расписанию
- **Лендинг** — простая страница на Tilda

См. [.kiro/specs/automation/](.kiro/specs/automation/)

## 📊 Метрики, на которые смотрим

Не на подписчиков, а на:
- Сколько людей написали `СОН` в директ
- Сколько ответили после получения PDF
- Сколько спросили цену
- Сколько купили бета-версию
