# Требования: Автоматизация воронки «Тихий вечер»

## 🎯 Цель

Автоматизировать воронку продаж продукта «Тихий вечер» так, чтобы:
- Лид-магнит выдавался **24/7 без участия автора**
- Прогрев шёл по расписанию **автоматически**
- Платежи принимались **онлайн** через Tinkoff Касса / ЮKassa
- Доступ к продукту выдавался **автоматически** после оплаты
- Контент в Telegram-канале публиковался **по расписанию**

## 👥 Стейкхолдеры

- **Автор продукта** (пользователь Kiro) — контент-мейкер, не разработчик
- **Покупатель** — женщина 27–42, перегруженная, не готова к сложным интерфейсам

## 📋 Функциональные требования

### FR-1. Telegram-бот воронки

**FR-1.1.** Бот должен принимать команду `/start` и приветствовать пользователя.

**FR-1.2.** Бот должен реагировать на ключевое слово `СОН` (в любом регистре):
- Отправлять PDF-файл лид-магнита «Почему ты просыпаешься разбитой?»
- Сохранять пользователя в базу как «получил лид-магнит»
- Запускать таймер прогрева

**FR-1.3.** Бот должен реагировать на ключевое слово `ТИХО`:
- Отправлять описание продукта «Тихий вечер»
- Отправлять кнопку «Купить за 1990 ₽»
- Сохранять пользователя как «заинтересован в продукте»

**FR-1.4.** Бот должен автоматически отправлять серию прогрева:
- День 1 (через 1 час после `СОН`): сообщение «Узнавание боли»
- День 2 (через 1 день): сообщение «Разрушение мифа»
- День 3 (через 2 дня): сообщение «Мини-польза»
- День 4 (через 3 дня): сообщение «История / кейс»
- День 5 (через 4 дня): сообщение «Продажа» с кнопкой покупки

**FR-1.5.** Бот должен останавливать прогрев, если пользователь:
- Купил продукт
- Написал «стоп» / «отписаться»

### FR-2. Приём платежей

**FR-2.1.** Бот должен генерировать ссылку на оплату 1990 ₽ через **Tinkoff Касса** или **ЮKassa** (выбор пользователя).

**FR-2.2.** После успешной оплаты (webhook от платёжной системы) бот должен:
- Отправить покупателю ссылку-приглашение в Telegram-пространство «Тихий вечер»
- Сохранить статус «оплатил» в базе
- Уведомить автора (тебя) о новой продаже

**FR-2.3.** Если оплата не прошла — мягкое follow-up через 24 часа.

### FR-3. Доставка продукта

**FR-3.1.** Купивший автоматически добавляется в закрытый Telegram-канал/группу программы.

**FR-3.2.** Бот должен по расписанию (раз в день в 09:00) отправлять покупателю урок дня:
- День 1: Почему ты устала, но не спишь
- День 2: Вечерний перегруз
- День 3: Ритуал выключения
- День 4: Если голова не замолкает
- День 5: Если просыпаешься ночью
- День 6: Утро без насилия
- День 7: Личный шаблон

**FR-3.3.** На 7-й день бот должен отправить опрос-отзыв.

### FR-4. Автопостинг в Telegram-канал

**FR-4.1.** Должна быть возможность загрузить расписание постов на 30 дней (CSV / Google Sheets / Notion).

**FR-4.2.** Бот должен публиковать посты в Telegram-канал по расписанию.

**FR-4.3.** Поддержка форматов:
- Текстовые посты
- Посты с фото
- Посты с видео (рилсы)
- Опросы
- Кнопки с CTA

### FR-5. Аналитика и учёт лидов

**FR-5.1.** База данных пользователей с полями:
- telegram_id
- username
- имя
- источник (СОН / ТИХО / другое)
- дата первого касания
- получил ли лид-магнит
- ответил ли на follow-up
- спросил ли цену
- статус оплаты
- дата оплаты
- день программы (для покупателей)

**FR-5.2.** Команда `/stats` для автора показывает:
- Всего лидов за период
- Конверсия СОН → ТИХО
- Конверсия ТИХО → продажа
- Сумма выручки

**FR-5.3.** Автоматический экспорт в Google Sheets (опционально).

## 🔒 Нефункциональные требования

### NFR-1. Производительность
- Ответ бота на сообщение: < 2 секунды
- Поддержка минимум 1000 одновременных пользователей

### NFR-2. Надёжность
- Uptime: 99% (плановые перезагрузки допустимы)
- Логирование всех действий бота
- Резервная копия базы данных раз в сутки

### NFR-3. Безопасность
- Webhook от Tinkoff/ЮKassa проверяет подпись
- Токены и ключи в `.env`-файле (не в коде)
- База лидов не доступна никому, кроме автора

### NFR-4. Удобство использования (для автора)
- Конфигурация через `.env` файл и YAML
- Тексты сообщений можно редактировать **без изменения кода**
- Просмотр логов через команду в боте

### NFR-5. Развёртывание
- Self-hosted (пользователь готов хостить сам)
- Минимум зависимостей (Python + БД + один процесс)
- Docker-compose для запуска одной командой

### NFR-6. Стоимость инфраструктуры
- VPS: 200–500 ₽/мес
- БД: SQLite (бесплатно, файл) или PostgreSQL
- Без подписок на сторонние сервисы

## 🎯 Критерии приёмки (MVP)

Бот считается готовым, когда:

- [ ] Реальный пользователь может написать `СОН` и получить PDF
- [ ] Прогрев из 5 сообщений приходит автоматически
- [ ] Реальная оплата через Tinkoff/ЮKassa проходит и доступ открывается
- [ ] Покупатель получает урок дня каждый день
- [ ] Автор видит статистику командой `/stats`
- [ ] Бот восстанавливается после перезапуска (state в БД)
- [ ] Документация по запуску есть в README

## 🚫 Что НЕ делаем в MVP (отложим)

- ❌ Интеграция с Instagram (только Telegram)
- ❌ Многоязычность
